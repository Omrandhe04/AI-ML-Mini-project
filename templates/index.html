1. Model Backbone: DenseNet-121

                        
Stanford's CheXNet proved DenseNet-121 achieves radiologist-level performance on pneumonia and thoracic findings. Unlike ResNet which adds feature maps, DenseNet concatenates all preceding layers:

                        x_l = H_l([x_0, x_1, ..., x_{l-1}])
                        
    
                            
  • Feature Reuse: Low-level lung margins and rib edge features flow directly into high-level layers.
    • 
                            
  • Pretraining: Initialized with ImageNet or torchxrayvision medical weights.
    • 
                            
  • Classifier: Global Average Pooling + Dropout(0.2) + Linear(1024, 14).
    • 
                        

                    


                    

                        
2. Explainability: Grad-CAM Formulation

                        
Generates visual explanations without requiring costly bounding box annotations during training:

                        

                            $$\alpha_k^c = \frac{1}{Z} \sum_{i} \sum_{j} \frac{\partial y^c}{\partial A_{i,j}^k}$$
                            $$L_{\text{Grad-CAM}}^c = \text{ReLU}\left(\sum_k \alpha_k^c A^k\right)$$
                        

                        
In DenseNet-121, extract activations and gradients at model.features.denseblock4.denselayer16.conv2.

                    


                    

                        
3. Patient Leakage Prevention (#1 Pitfall)

                        

                            CRITICAL EXAM POINT: Never use standard random train/test split!
                        

                        
Patients in the NIH dataset have multiple follow-up visits. Splitting purely by image indexes puts the same patient in both train and test sets, artificially inflating AUROC by 5–15%. Always split grouped by Patient ID.

                    


                    

                        
4. Evaluation Metrics for Medical AI

                        
    
                            
  • AUROC: Primary clinical metric; handles class imbalance well.
    • 
                            
  • Youden's J Index: $J = \text{Sensitivity} + \text{Specificity} - 1$ to calibrate disease-specific thresholds (do NOT default to 0.5).
    • 
                            
  • Pointing Game / Bounding Box IoU: Validates if Grad-CAM peak lies inside NIH ground-truth radiologist boxes.
    •
